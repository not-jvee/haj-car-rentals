HAJ CAR RENTALS — SIMPLE STATIC STARTER

This version uses only HTML, CSS, and JavaScript. It is intended as a simple
starter that can be published with GitHub Pages.

FILES
- index.html
- assets/style.css
- assets/app.js

RUN LOCALLY
1. Extract the folder.
2. Open the folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.

PUBLISH WITH GITHUB PAGES
1. Create a GitHub repository (for example: haj-car-rentals).
2. Upload index.html and the assets folder to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish the site.

IMPORTANT DATA LIMITATION
This starter saves records using browser localStorage. Records are stored only
in the browser and device where they are entered. They do not synchronize to
other employees' devices, and clearing browser data can erase them. GitHub
Pages does not provide a database or secure user login.

Do not publish real customer information in a public repository. For real
multi-device business use, add a hosted database and authentication (for
example Supabase) before storing actual customer data.

RECEIPTS
Use the Receipts section or Reservations > Receipt. The browser print dialog
lets you print or choose Save as PDF. Receipt styling is optimized for printing.

This starter is a foundation, not a complete secure production system.


RENTAL CONTRACT FEATURE
Open Reservations and click Contract, or open Rental contracts from the sidebar and choose Generate / Print. The generated contract fills in the saved customer, vehicle, plate, and rental dates. Color is set to Space Grey and fuel type to Unleaded. Use the browser print dialog to print or save as PDF.
